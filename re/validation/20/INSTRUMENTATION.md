# Original-process observation recipe

**NOT RUN — WINDOWS HOST REQUIRED.** This is a binding/recording specification for an operator-supplied Windows debugger/profiler. No automatic CLR tracer, injected gameplay code, replacement parser, fake input timestamp or state simulator is supplied. `probes.json` consolidates existing E10–E19 metadata; it does not contain runtime addresses or new gameplay discoveries.

## Binding and identity

1. Pin archive/EXE hashes from `inputs.json`; verify disk and loaded-module identity in the actual process. Expected EXE Module MVID is `0ec6eb3a-4adc-4b54-1f45-8b4ed40b33b1`. MVID/hash identify this supplied binary, not official authenticity. Record actual process architecture, CLR module/version/hash, debugger/profiler version/hash, AppDomain/module identity and any instrumentation patches.
2. Resolve each selected MethodDef token against that module. Confirm owner/signature/body identity, concrete runtime receiver and virtual dispatch. Body SHA256 is the original method body including its CIL header, not native JIT code. Original RVA/file offsets must not become breakpoints in JIT code.
3. For each enabled location, record current JIT code version, native address plus IL map and debugger/profiler binding ID in a private copy of `bindings.template.json`. Templates remain unverified until actually resolved. Re-JIT, tier changes, in-memory rewriting or module reload require new binding records. If the tool cannot map a consumed operand at optimized code, record unavailable/reason and stop that comparison; do not call another original helper to manufacture it.
4. Use debugger object identities/handles with process and GC lifetime scope. A raw address is not a persistent object identity across GC. Do not invoke `GetHashCode`, `ToString`, property getters, clock functions, input polling, resource methods or modifier conversions merely for logging. Disable automatic debugger property/function evaluation where supported. Capture the return/operand of the conversion the original already executes; distinguish direct field snapshots from consumed values.
5. Instrument only a method group needed by the current case. First import/entry and visible untraced controls; then circle; then tracking; then combo/completion; then failure. Log original exception/early-return sites and missing hooks. A breakpoint can change cadence; use explicit `natural_debugger_paused` for naturally reached state with pauses, `forced_probe` for changed fields/clocks/invocations, and `natural_low_overhead` only for genuinely measured nonstopping recording. Do not relabel a debugger-altered run as normal timing.

## Record representation and overhead

- Follow `trace.schema.json`; IDs tie every record to a run/case/probe/binding. `seq` is collector emission order, not proof of a single atomic cross-thread execution order. `thread_seq` preserves each producer's order. Preserve timestamps/order as captured; never sort by gameplay time, which can jump.
- QPC ticks are decimal **strings**; frequency is an actual measured run-manifest integer. Record thread ID and hook-entry/exit QPC without invoking original game clocks. Measure collector duration, event loss, buffering and any blocking/stepping. Do not write synchronous large dumps on the gameplay thread and call overhead negligible.
- `values` holds original typed text and `capture_kind`: consumed_operand, argument, return, branch_result, field_snapshot or unavailable. Single/Double require the exact **little-endian original bytes** as8/16 hex digits as well as text; capture NaN/infinity without JSON NaN tokens. If bits or a value cannot be obtained, use Unknown/unavailable with a reason. Do not reconstruct consumed float bits from a rounded display string.
- For references, record null versus nonnull, original runtime type/token, owner and stable debugger identity scoped to process/lifetime. Put type/owner detail in `text` and process-local ID in `reference_id`. Arrays/list text is JSON preserving original order/types. Primitive field snapshots are allowed, but cannot be passed off as earlier consumed values.
- Link settings/environment/bindings/trace/capture/overhead files by private manifest artifact IDs/SHA256. Save any in-memory instrumentation modification and its range/hash privately; never claim an unmodified original run if methods were rewritten. Preserve original IL identity as well as instrumentation changes.
- Compare at least measured untraced versus traced repeat duration/cadence and missed/drop counts; aim for three each when practical. Report actual sample counts, median/max and variation, not a predeclared zero cost. A managed-update sample is not a frame-present time, input-device latency or audible event. If overhead changes classification/backlog, report that confound and repeat with fewer probes. A full performance framework is outside scope.

## Manual acceptance review

`pilot.py validate` checks record structure/hash/declared provenance only; it cannot recognize a truthful debugger trace or prove the static rules. It does not check every JSON-Schema keyword or automate original-result comparison. Review real bindings, consumption-site samples, capture/process evidence, natural versus paused/forced provenance and overhead together.

For each case fill hypothesis, exact input/settings/environment hashes, actual status/procedure, original observed operands, comparison MATCH/MISMATCH/INCONCLUSIVE, evidence IDs, confounds/config changes and smallest follow-up. A mismatch belongs in a new appended finding; historical reports remain unchanged. Do not count intended key time, example records, debugger-forced bits or missing unbound hooks as natural Windows success/failure evidence.

E20 is accepted only after pinned original Windows execution/import/entry; natural ordinary-circle and slider-checkpoint activity; both natural successful/failed components with original operands; observed combo writes; and matched SD/no-SD fail/continue evidence or its actual original-runtime blocker, with comparisons and limitations. This packet alone satisfies none of those runtime criteria.
